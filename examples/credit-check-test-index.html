Testing Flow

  1. Start with the Order/Contact Details Page
  2. Enter an email address in the email field
  3. Verify the email is stored in localStorage (check the status display)
  4. Click "Continue to Booking Complete" or navigate to the Booking Complete Page
  5. The credit check dialog should appear, replacing the default booking content
  6. Click "Sjekk kreditt" (Check credit) to test the BankID authentication flow

Note: The BankID authentication will require actual Criipto credentials. For testing without BankID, you can check the console logs to see the flow.

Configuration

The test pages use the following configuration:

  • Organization ID: test-organization-id
  • Integration Type: stora
  • Criipto Domain: mediaperformance-test.criipto.id
  • Criipto Client ID: urn:my:application:identifier:28040

Update these values in the HTML files to match your actual configuration.
